## Projects

### POSBright / Smart ERP

Retail POS for shops that sell **cash and credit**. Owners see stock, collections, and profit. Tellers stay on the register.

| Repo | What it is |
| --- | --- |
| [smart-erp-frontend](https://github.com/thanuj88/smart-erp-frontend) | React POS and admin UI: inventory, sales, customers, installment payments, six languages, dark/light theme. Members are looked up by local phone. |
| [smart-erp-backend](https://github.com/thanuj88/smart-erp-backend) | Node.js + Express + DynamoDB API: multi-tenant auth, cash/installment sales, inventory, overdue collections, returns, JWT roles. |

### D2 Diagram Editor

Browser UML/D2 editor with serverless AWS rendering.

| Repo | What it is |
| --- | --- |
| [d2-diagram-frontend](https://github.com/thanuj88/d2-diagram-frontend) | React + TypeScript + Vite + Material UI. Edit D2, zoom/pan SVG, Cognito login, talks to the diagram API. |
| [d2-diagram-backend](https://github.com/thanuj88/d2-diagram-backend) | AWS CDK stack: API Gateway, Lambda, DynamoDB, S3 for SVGs, Cognito, and a D2 renderer service. |
